# AI Password Auditor

A simple Python tool to audit passwords and classify their strength.

## Features
- Login system for multiple users
- View a list of common passwords and their strength
- Check the strength of a custom password
- Classifies passwords as Weak, Medium, or Strong

## Usage
1. Run `python main.py`
2. Login with your username and password
3. Choose:
   - `1` to show a predefined password list with scores
   - `2` to check a custom password (shows only classification)
