# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 2.0.x   | ✅ Yes     |
| 1.x     | ❌ No      |

---

## Reporting a Vulnerability

If you discover a security vulnerability or any unexpected behavior, please report it **privately**.

**Do NOT open a public GitHub issue for security-related reports.**

---

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and resolved before publicly disclosing any vulnerability.

---

## Disclaimer

This project is intended **strictly for educational and ethical cybersecurity purposes**.

Any misuse of this software is the sole responsibility of the user.
